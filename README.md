# OSM What’s New Japan

OpenStreetMapで最近追加・編集された地物を、地図、全国・都道府県別レポート、更新密度、マッパープロフィールとして表示する静的Webフロントエンドです。

データ収集、集計、API、管理機能は「OSM Japan Changes」へ移行しました。このリポジトリの画面は、次のAPIを利用します。

```text
https://armd-01.sakura.ne.jp/osm-japan-changes/api.php
```

## 主な機能

- 更新された地物をMapLibre地図とタイムスケールで再生
- OSMFJのPOI付き地図スタイル上に、更新された地物をカテゴリ別マーカーで表示
- 更新地物を暗い広域地図上で再生する「OpenStreetMap NIGHTSCAPE」デモ
- 地図、分析、更新密度を共通ナビゲーションから切り替え
- 期間、都道府県、代表タグ、新規・更新種別による絞り込み
- POI詳細から代表タグのOSM Wikiページを表示
- 全国および都道府県別の件数、代表タグ、マッパー、日別更新数の集計表示
- GeoJSON・CSV出力、各分析リストのCSV出力、表示条件を復元できるURL共有
- マッパー別のレベル、バッジ、活動地域、最近の活動、関連マッパーを表示するプロフィール
- スマートフォンでも常時表示する、地図・分析・更新密度・マッパーの画面切り替えタブ
- 各画面の短い見方案内、共通ヘルプの用語補足
- 分析・マッパー画面と共通ヘルプから、LearnOSM日本語ガイドへつながる地図編集の参加案内
- 初回利用ガイドと各画面共通のヘルプ

### タイムライン表示

地図データの読み込み完了後は、タイムラインを停止したままスライダーを最新位置へ移動します。共有URLに時刻が含まれる場合は、その指定位置を復元します。最新位置で再生ボタンを押すと先頭へ戻って再生を開始します。

タイムライン上部の日時は「開始日時〜選択中の日時」、件数は開始日時から選択中の日時までの累積件数として表示します。

タイムスケールは最小・最大位置まで塗りつぶされ、つまみの位置と選択範囲が一致するよう表示します。

## 構成

Webアプリケーションはリポジトリ直下にあります。

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` | 更新地図、タイムスケール、都道府県・タグ絞り込み |
| `details.html` / `details.js` | 全国・都道府県別の分析画面 |
| `coverage.html` / `coverage.css` | 約1kmメッシュ単位の更新密度 |
| `profile.html` / `profile.js` / `profile.css` | マッパープロフィール |
| `map-view.js` | 各画面間の地図中心位置・ズーム共有 |
| `help.js` | 初回利用ガイドと共通ヘルプ |
| `modal.js` / `modal.css` | 共通モーダル |
| `data/` | API設定、タグの翻訳、カテゴリ、マーカー、都道府県GeoJSON |
| `tiles/` | MapLibre用地図スタイル（通常表示は `osmfj_poi.json`） |
| `image/` / `icon/` | 画像と地図アイコン |

公開画面ではGoogle Analytics 4（測定ID：`G-V4357J57C7`）を使用してアクセス状況を計測します。Analytics Cookieは現在のホストだけで利用します。

## API設定

各画面は `data/config.jsonc` の `apiUrl` を共通して使用します。

```jsonc
{
  // 各画面で共通して使用するAPIエンドポイント
  "apiUrl": "https://armd-01.sakura.ne.jp/osm-japan-changes/api.php"
}
```

`apiUrl`にはHTTPまたはHTTPSの絶対URL・相対URLを指定できます。別オリジンのAPIを指定する場合は、API側でこのフロントエンドのオリジンを許可するCORS設定が必要です。

## 分析画面

`details.html`では、マッピング対象を検討しやすいよう、地域・代表タグの比較、更新の推移、マッパーの活動状況の順に表示します。

- **地域 × 代表タグ**：選択地域・期間・更新種別で件数の多い上位5タグを全47都道府県で比較します。都道府県を行、タグを列に配置し、北海道・東北／関東／中部／近畿／中国／四国／九州・沖縄の7地域で区切ります。
- **その他・合計**：「その他」は各都道府県の合計から表示中の上位5タグを引いた件数です。色の濃さは列ごとに比較し、同じタグで件数の多い地域ほど濃く表示します。更新0件が未整備を意味するとは限りません。
- **累積（新規・更新）**：選択期間の開始日からの累積地物数を積み上げ表示します。新規・更新による絞り込みとCSVダウンロードに対応しています。
- **集計概要**：更新地物数とマッパー数に、選択期間の日数で単純に割って四捨五入した日平均を併記します。
- スマートフォンでは表のタグ名を複数行に折り返し、横スクロールを抑えます。表には見出しと都道府県名を固定し、CSVには上位タグ・その他・合計を出力します。

### 集計期間

集計できるのは日本時間の昨日までです。初期値の1週間は昨日を終了日とする7日間で、プリセットを選び直すと昨日を終了日として期間を設定します（1ヵ月は30日、半年は183日、1年は365日）。

開始日は手動で変更でき、プリセットではその開始日から終了日を自動計算します。指定期間全体が昨日までに収まるよう、開始日の上限を設定しています。「任意」を選ぶと開始日・終了日の両方を指定できます。日数は開始日と終了日の両方を含めて数えます。

### 都道府県のURL指定

`details.html?prefecture=27` のように、都道府県コード（01〜47）で地域を指定できます。例：`01` は北海道、`13` は東京都、`27` は大阪府です。`JP-27` 形式も受け付けます。指定がない場合や無効なコードの場合は全国表示になります。

地図で都道府県を選ぶとURLにもコードが反映され、そのURLを共有できます。「全国へ戻る」でコードを除去します。

## 初めて利用する方への案内

各画面のヘッダーに画面切り替えタブを常時表示し、現在の画面を強調しています。スマートフォンでもメニューを開かずに移動できます。サブタイトルは「OpenStreetMap 最近追加・更新された場所」とし、地図の導入文や各画面の案内で見る目的を説明しています。

分析・マッパー画面の上部には、身近な場所の追加・修正を始めるための短い案内と、[LearnOSMの日本語ビギナーズガイド](https://learnosm.org/ja/beginner/)へのリンクを設けています。サイト名から開く共通ヘルプにも参加案内と「地物」「代表タグ」「マッパー」の用語補足があります。

更新密度は最近の更新の集中を示すもので、情報の不足や整備率を直接示すものではありません。案内では実際の地図と比較することを勧めています。

## ローカル確認

PHPやデータベースは必要ありません。リポジトリのルートで静的Webサーバーを起動します。

```shell
python3 -m http.server 8000
```

ブラウザーで `http://127.0.0.1:8000/` を開きます。ローカル画面からも、設定済みの「OSM Japan Changes」APIへ接続します。

## 公開

公開先は [whatsnew.openacrossbase.net](https://whatsnew.openacrossbase.net/) です。GitHub Pagesはこのリポジトリの `main` ブランチのルートを公開元としており、`main` へのpush後にビルド・配信されます。

別のWebサーバーへ配置する場合は、リポジトリ直下の静的サイトファイルとアセットディレクトリを配置します。HTML、CSS、JavaScript、JSON、GeoJSON、画像、地図スタイルのみで動作します。

公開後は次を確認してください。

- 地図、分析、更新密度、プロフィールの各画面が開く
- APIリクエストが成功し、データが表示される
- `data/`、`tiles/`、`image/`、`icon/`の静的ファイルが配信される
- 別オリジン構成の場合、ブラウザーでCORSエラーが発生しない
